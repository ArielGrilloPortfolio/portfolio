FIRULET MAP

De tu guitarra
a un mapa de notas.

Una ayuda para sacar melodías de oído. Cargá una grabación de guitarra, explorá las notas y los bends probables, y contrastá el resultado con el audio original.

Descargar para Windows ↓Leer la guía

v0.1.0 · Windows x64 · ZIP portable · 190 MB

La app está en inglés. No necesitás instalar .NET ni Python.

01

Cargá tu grabación

Guitarra aislada, una nota a la vez, con distorsión y sin otros efectos.

02

Explorá el mapa

Revisá alturas, inicios, finales, curva de afinación y zonas inciertas.

03

Volvé a escuchar

Reproducí el original o una nota seleccionada, con zoom y cursor sincronizado.

ENTRADA COMPATIBLE

Un WAV, una guitarra.

  • WAV mono PCM de 16 bits.
  • 44,1 o 48 kHz; hasta 40 segundos.
  • Una línea melódica, con distorsión; sin reverb, delay ni otros efectos.
  • No necesitás BPM, compás, MIDI ni señal DI.

El análisis se ejecuta en tu equipo y no sube automáticamente el audio.

QUÉ ESPERAR DE LA 0.1.0

Una propuesta para revisar.

La detección es imperfecta: algunas notas débiles, repeticiones, finales o bends pueden necesitar revisión. Usá el oído como referencia.

No incluye acordes, separación de instrumentos, edición de notas, exportación MIDI ni guardado de análisis. El primer análisis puede tardar más.

La app aún no tiene firma digital. Si Windows impide abrirla, anotá el mensaje y contalo en el feedback.
