# FIRULET MAP 0.7.0 for Windows x64

The desktop UI moves to Avalonia. Local monophonic guitar analysis, .firulet documents, original audio and synth playback, editing, reanalysis and MIDI remain available.

- **Portable.** Extract the entire ZIP and run `FiruletMap.Desktop.exe`.
- **Installer.** Extract the ZIP and run setup. Close FIRULET MAP before upgrading from 0.6.8. Setup requires administrator privileges.
- Both packages bundle private .NET and Python runtimes. Keep your .firulet documents with their WAV files. The packages are unsigned.
