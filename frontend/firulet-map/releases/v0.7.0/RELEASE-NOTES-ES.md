# FIRULET MAP 0.7.0 para Windows x64

La interfaz migra a Avalonia. Se mantienen el análisis local de guitarra monofónica, los documentos .firulet, la escucha de audio y synth, la edición, el reanálisis y el MIDI.

- **Portable.** Extraé todo el ZIP y ejecutá `FiruletMap.Desktop.exe`.
- **Instalable.** Extraé el ZIP y ejecutá el setup. Cerrá FIRULET MAP antes de actualizar desde 0.6.8. El instalador requiere permisos de administrador.
- Ambas distribuciones incluyen .NET y Python privados. Conservá tus documentos .firulet junto con sus WAV. Los paquetes están sin firma.
